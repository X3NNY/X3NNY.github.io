                                                                        # 1.1. 误差和误差限

                                                                        1. 绝对误差

                                                                          e∗=x∗−x e^{*} = x^{*} - x e∗=x∗−x

                                                                          即真实值和近似值的绝对差，一般情况我们不知道真实值，所以求不出绝对误差。但是可以求绝对误差限∣e∗∣<ε\vert e^{*}\vert < \varepsilon∣e∗∣<ε。

                                                                        2. 相对误差

                                                                          er∗≈e∗x∗=x∗−xx∗ e^{*}_r \approx \frac{e^{*}}{x^{*}} = \frac{x^{*} - x}{x^{*}} er∗​≈x∗e∗​=x∗x∗−x​

                                                                          相对误差限为∣er∗∣<εr\vert e^{*}_r\vert < \varepsilon_r∣er∗​∣<εr​。

                                                                        # 1.2. 有效数字

                                                                        • 若∣e∗∣≤12×10m−n\vert e^{*}\vert \le \frac{1}{2}\times 10^{m-n}∣e∗∣≤21​×10m−n，且x∗=±0.a1a2a3…an×10mx^{*} = \pm 0.a_1a_2a_3\dots a_n \times10^{m}x∗=±0.a1​a2​a3​…an​×10m，则x∗x^{*}x∗有nnn位有效数值。
