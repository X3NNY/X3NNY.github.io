英语一

原创Xenny2025/1/10约 2056 字大约 9 分钟考研英语

英语一

  • 2024考研「英语一」笔记&复习要点。

长难句

找主干

看标点，做判断（聚焦）

  • 逗号：若介词短语、从句、非谓语在前，则主干在后。反之则主干在前
  • 分号：起并列作用，则主干在前，后面为并列句。
  • 冒号：补充/说明/解释，即同位语，则主干在前。
  • 破折号：同冒号。
  • 两个破折号：中间一定为插入语。
  • 两个逗号：中间为插入语也可能是主干，得看前后有没有主干。

数谓语动词，数连词

  • 谓语动词三种形式
    • 各种时+态
      • 汉语依赖时间状语：昨天、明天
      • 英语依赖动词形式变化：are、were
      • 故谓语动词要包含时间+状态，非谓语动词只包含状态
      • 则各种时态就是不同的时+态组合，但是有些时候会进行简化
      • I loved you -> I did love you
      • 时间承载词：did，do，will，would
      • 状态词：一般do，进行be，完成have
      • 例如
        • 过去完成时：did have do -> had done
        • 将来完成进行时：will have be do -> will have been doing
        • 过去将来完成进行时的被动语态：did will have be be do -> would have been being done
      • 时间或状态中间可能会有介词短语或副词
      • 但重点是看有无完整的时+态才算谓语动词
    • 语态
      • be done，被动语态
    • 情态动词
      • can/may/must/shall/should/would/will/might do sth
      • 情态动词+动词原形，整体作谓语
      • 改变动词的语气，不能单独出现
      • 例如
        • be able to do sth
        • have to do sth
        • ought to do sth
  • 连词
    • 只数连接句子的词，连接短语的不要
    • 是否连词看是否让句子丧失独立性
    • 连词的作用是让句子无歧义，即获得单一主干
    • 并列连词：or/and/xxx，主干在前面
    • 从属连词：while/when，主干在后面
  • 主干公式
    • 句子连词/动词 = (n-1)/n
    • 推算出主语和谓语动词

三个难点

  • 主谓宾宾和主谓宾补的区分
    • 宾语和宾补拿出来加be动词，若语义部分一致则为主谓宾补
    • John's father gave him a dog -> He is a dog 不一致，故dog作宾语
    • John's father called him a dog -> He is a dog 部分一致，故dog作补语
  • 区分did（谓动）和done（非谓）同体
    • 即过去式和过去分词同形式
    • 还是加be动词看语态和语义是否变化，变了说明是过去式
    • a paper published in England（论文被出版） -> a paper be published（论文被出版） -> 此时published是过去分词
  • 主干公式的特例
    • 没有特例，但是连词/谓动可能会被省略
    • 故发现不符合时，一般都是连词被省略了

复杂修饰成分

基本成分

  • 主语：动作的发出者或描述对象
  • 谓语：承载时态、语态、情态信息的动作
  • 宾语：跟在及物动词、非谓、介词。被动作作用/介绍的对象
  • 补语：补充说明主语（主补）或宾语（宾补）的内容
    • 补充说明：同等关系+修饰
    • 其中主语和补语的连缀动词可以直接用be替换，看语义是否改变。
    • 所以填补语时看修饰的谁
      • All men are created equal，equal修饰men，意味着不管是怎么创造的，都是平等的
      • All men are created equally，equally修饰created的过程，意味着所有人创造的过程平等，不代表人平等。

修饰成分

  • 定语：修饰名词

  • 状语：修饰其他的

  • 构成

    • 介词短语
      • 介词+名词词组（限定词+修饰词+名词）
    • 从句
      • 从属化连词 + 主干
    • 不定式
      • to do sth
    • 分词
      • doing，注意和动名词区分
      • done

汉化过程

  • 词意（语境为王）
    • 合理性，一词多译
      • develop new software 开发新软件
      • develop new habits 养成新习惯
      • pen a letter 写一封信
    • 完整性，增词/减词
      • in evolution 在进化中 -> 在进化的过程中
      • report the finding 报道发现 -> 报道发现的成果
      • part of the political and economic bedrock 政治和经济的基础（的一部分）
  • 语序
    • 全局状语：汉语中只放句首
    • 定语
      • 前置定语和修饰内容做为一个整体
      • 后置定语往前置
      • 但定语太长时，单独做句翻译
    • 复杂并列结构
      • N of A and B of C
        • 若前后完整句子 -> A N and C B
        • 若and并列的A和B，则看成整体 -> C (A and B) N
    • 总结：基本成分不变，修饰成分前置

技巧

  • 被动句的翻译
    • 被动 -> 主动
      • 无主句增加泛指主语，例美洲狮被发现->人们曾经发现了美洲狮子
    • 其他词替代：由...所/为...所/由...来
  • 定语的翻译
    • 信息量少（<6个单词）：倒序前置，···的
    • 信息量多：单独翻译
      • 非限制定从：，而这···
      • 同位语从句：即，/也就是，/：
  • It做形式主语，主语为从句或to do sth
  • 宾语后置：宾语太长
  • 名称的修饰成分
    • 左二（名词前）
      • 限定词：冠词、量词、叙述词、指示代词
      • 修饰词：形容词、形容词性的词语
    • 右六（名词后）
      • 定语从句、介词短语、不定式
      • 形容词、分词短语、同位语

选择题的固有缺陷

  • 问题的暗示

    • 求同
      • 5个题干+主旨题4个选项
      • 找重复的词
        • 名词
        • 设计文章内容
        • 词组优先
    • 题干给出的真实信息
      • 字面意思本身（题干+选项共性+原文）
      • 字面意思存在前提（必要条件）
        • 为什么+观点 -> 观点成立
        • 建议/应该+do sth -> sth还没做
        • 禁止+do sth -> sth被做过
        • A有利，应该去做 -> 不会同时有更大的弊
        • 可以做一件事 -> 主体有能力/条件可以做
      • 对字面意思的逻辑推理
    • 题干的逻辑反应文章的逻辑
      • 主旨的考察角度
        • 文章的主旨内容
        • 文章的组织结构
        • 作者态度（语气）
      • 二分法
        • 一部人xxx -> 作者不支持xxx
        • A认为xxx -> B不认为xxx

  • 选项的暗示

    • 相关性
      • 选项在相关项中：相似或相反（负相关）
      • 无关
        • 具体内容+无具体内容：大概率选无内容
        • 具体内容：内容做题法
      • 找出错概率较小的选项
        • 选项都说的词
        • 全文都说的词
        • 虚的词
        • 大道理的话
        • 约等于全集的话（否定词+绝对词）
    • 重复性
      • 结构的共性
      • 词语
        • 一定对
        • 反向定位

  • 原文的暗示

  • 前后题一致性的暗示

    • 题目来自同一文章：主旨一致

阅读应用

  • 细节题（能在原文中定位）
    • 普通细节题
    • 特殊细节题：题干问法比较固定
      • 例子题
        • 特征：xxx to do sth.
        • 作者使用/引入xxx（的目的）是xxx
        • 开篇例：文章一开篇就是例子
          • 找例子结束后的那句话（优先 ）
          • 找不到则是全文主旨
        • 段中例：求同求异，然后找观点句
          • 观点句在前（前一句/前半句）
          • 观点在段落第一句（段落主旨）
        • 整段例：除第一段外，整个一段都是例子
          • 文章主旨
          • 前一段段落观点句
      • 推断题
        • 特征： 言外之意，引申意
        • 可能正确的答案
          • 出现may
          • 情态动词
        • 推细节（词或词组）
          • 细节所在本句，防并列
          • 反向定位、判断信息正误，对的不一定对，错的一定错，
        • 推段落
          • 一个整段：第一句，大写转折，最后一局（否定词/转折词） -> 段落大意
          • 多个整段：每段第一句
        • 推全文
          • 前4题：推段落
          • 第五题：最后一段或主旨
      • 态度题
        • 特征
          • according to 人名、one's opinion/view
          • (hold/argue/state/note/assume/maintain/suspect/contend) + that
          • attitude、feel、agree、believe、conclude
        • 某人态度
          • 人+说话+（细节），防并列
          • 例如
            • V. + that
            • ...., xxx said, xxxx
            • consider/regard/view/see/think A as B
            • 某人的研究/实验得出结论
            • 某人和团队的研究/实验得出结论
        • 作者态度
      • 词汇题
      • 句子题
  • 主旨题（不能在原文中定位）
