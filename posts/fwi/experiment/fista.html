                    # FISTA解决地震反演问题 [WIP]

                    • 迭代收缩阈值算法（Iterative shrinkage-thresholding algorithm, ISTA）是一种用于信号处理和图像重建的优化算法。

                    # 梯度下降

                    • 对于一个线性变换问题y=Ax+b\mathbf{y} = \mathbf{A}\mathbf{x} + \mathbf{b}y=Ax+b，其中A\mathbf{A}A和y\mathbf{y}y已知，b\mathbf{b}b为未知噪音，我们需要求解x\mathbf{x}x。

                      本质上这就是一个线性回归问题，从线性回归open in new window可知我们可以使用梯度下降解决这个问题。

                    # ISTA

                    • ISTA也是基于梯度下降算法，它的关键在于对{xk}\{x_k\}{xk​}的选取。对于式1，当其满足Lipschitz连续条件，即f(x)f(x)f(x)的导数有下界（最小下界称为Lipschitz常数L(f)L(f)L(f)）。此时对于任意L≥L(f)L\ge L(f)L≥L(f)，有

                      f(x)≤f(y)+⟨x−y,∇F(y)⟩+L2∥x−y∥2,(3) f(\mathbf{x})\le f(\mathbf{y}) + \langle\mathbf{x}-\mathbf{y},\nabla F(\mathbf{y})\rangle + \frac{L}{2}\lVert \mathbf{x}-\mathbf{y}\rVert^2,\tag{3} f(x)≤f(y)+⟨x−y,∇F(y)⟩+2L​∥x−y∥2,(3)

                      对于所有x,y∈Rn\mathbf{x,y}\in \mathbb{R}^nx,y∈Rn成立。此时在点xk\mathbf{x}_kxk​附近的函数值可近似表示为

                      f^(x,xk)≐f(xk)+⟨∇f(xk),x−xk⟩+L2∥x−xk∥2.(4) \hat{f}(\mathbf{x},\mathbf{x}_k) \doteq f(\mathbf{x}_k) + \langle \nabla f(\mathbf{x}_k), \mathbf{x}-\mathbf{x}_k\rangle + \frac{L}{2}\lVert \mathbf{x}-\mathbf{x}_k\rVert^2.\tag{4} f^​(x,xk​)≐f(xk​)+⟨∇f(xk​),x−xk​⟩+2L​∥x−xk​∥2.(4)

                      此时再进行梯度下降时，将点xk−1\mathbf{x}_{k-1}xk−1​处的近似函数取最小值的点作为下一次迭代起始点xk\mathbf{x}_kxk​，这便是proximal regularization算法。

                    • 上述思路只能解决无约束问题，ISTA主要用于解决带惩罚项（噪声）的优化问题，例如对于带范数规范化函数g(x)g(x)g(x)的约束优化问题

                      min⁡{F(x)≡f(x)+g(x):x∈Rn}.(5) \min\{F(\mathbf{x}) \equiv f(\mathbf{x}) + g(\mathbf{x}) : \mathbf{x} \in \mathbb{R}^n\}. \tag{5} min{F(x)≡f(x)+g(x):x∈Rn}.(5)

                      QL(x,y):=f(y)+⟨x−y,∇f(y)⟩+L2∥x−y∥2+g(x).(6) Q_L(\mathbf{x}, \mathbf{y}) := f(\mathbf{y}) + \langle\mathbf{x} - \mathbf{y}, \nabla f(\mathbf{y})\rangle + \frac{L}{2}\lVert\mathbf{x}-\mathbf{y}\rVert^2 + g(\mathbf{x}).\tag{6} QL​(x,y):=f(y)+⟨x−y,∇f(y)⟩+2L​∥x−y∥2+g(x).(6)

                      忽略常数项f(y),∇F(y)f(\mathbf{y}),\nabla F(\mathbf{y})f(y),∇F(y)，该函数的最小值表示pLp_LpL​可以写为

                    # FISTA

                    • FISTA与ISTA的区别在于迭代步骤中近似函数起始点y\mathbf{y}y的选择，ISTA使用前一次迭代求得的近似函数最小值点xk−1\mathbf{x}_{k-1}xk−1​，而FISTA使用另一种方法进行计算

                    • 同时由于Lipschitz常数计算复杂问题，FISTA同样有带回溯版本。

                      由理论证明FISTA的收敛速度可以达到O(1/k2)O(1/k^2)O(1/k2)。非常快。
